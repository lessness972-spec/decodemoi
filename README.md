# Décode-Moi — version polices Dee Kréations

Version prête pour GitHub / Cloudflare Pages.

## Interface
L’apparence de la version de référence est conservée : fond uni sombre, cartes, couleurs, titre, badge 12 et signature discrète.

## Polices
- The Seasons : titres et textes sérif
- Tangerine Bold : titre manuscrit

Les fichiers de police ne sont pas inclus dans le dépôt. Le navigateur utilise les polices si elles sont installées sur l’appareil, puis des polices système de secours. Aucune dépendance Google Fonts n’est utilisée.
